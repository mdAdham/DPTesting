Task 1 - Student Management

Create the following APIs:

* `GET /students` → Display all students.
* `POST /students` → Add a new student (`id`, `name`, `department`).
* `PUT /students/<id>` → Update only the student's department.

 Challenge Task (Intermediate)

Create a **Bank Account API**.

**Fields:**

* `account_no`
* `holder_name`
* `balance`

Implement:

* `GET /accounts` → Display all accounts.
* `POST /accounts` → Create a new account.
* `PUT /accounts/<account_no>` → Deposit an amount into the account by updating the balance.

> **Bonus:** If the account number doesn't exist, return:

json
{
    "message": "Account Not Found"
}
